# 🌦️ Weather App

A simple and stylish weather app built using **HTML**, **CSS**, and **JavaScript**. This project allows users to search for any city and get real-time weather information including temperature, humidity, wind speed, and weather conditions (Cloudy, Clear, Rain, etc.).

## 🚀 Features

- Search for weather in any city
- Displays:
  - Temperature (in °C)
  - Humidity
  - Wind speed
  - Weather condition with icon
- Clean and responsive UI

## 🛠 Technologies Used

- **HTML** – For basic structure
- **CSS** – For styling the layout and responsiveness
- **JavaScript (Fetch API)** – For getting real-time weather data from an external API
